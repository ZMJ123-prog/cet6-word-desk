# CET6 Word Desk

A local-first vocabulary study desk built from CET6 Section A word banks from 2021 through December 2025.

## Features

- 450 vocabulary records with Chinese meanings
- Flashcard review with four familiarity ratings
- English pronunciation using the browser speech API
- Spelling quizzes and a wrong-word list
- Search and filters by exam and learning status
- Progress stored locally in the browser

Open `index.html` locally or use the GitHub Pages site.
